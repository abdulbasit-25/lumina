# 🎬 LuminaStudio

> **AI-Powered Production Intelligence for the Future of Filmmaking**

LuminaStudio is a futuristic, AI-powered film production management platform designed to demonstrate how **database systems, modern frontend engineering, and intelligent analytics** can work together in a real-world production environment.

Built as an **Artificial Intelligence Lab / DBMS Lab academic project**, LuminaStudio simulates an end-to-end film production platform — from concept development and pre-production to shooting, post-production, and distribution.

---

## ✨ Overview

Modern film productions involve thousands of interconnected decisions involving:

- 🎬 Production planning
- 👥 Cast & crew management
- 📅 Scheduling
- 💰 Budget management
- 📊 Market analytics
- 🤖 Predictive intelligence
- 🎞️ Post-production
- 🌍 Distribution

LuminaStudio brings these workflows into a unified platform with an **AI-first production intelligence layer**.

The goal is not simply to manage projects, but to provide production teams with insights that help them **identify risks, optimize resources, and make better decisions before problems occur**.

# ⚙️ Getting Started

## Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

## Clone the Repository

```bash
git clone <your-repository-url>
cd LuminaStudio
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:8080
```

## Build for Production

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
